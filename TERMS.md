# Use and support

Agent Worksystem Builder is an experimental alpha distributed for evaluation. Users choose the project, files, trusted commands, model backends and execution budgets. Review generated changes and task evidence before relying on results. Installation does not establish an operating-system sandbox or grant access to third-party accounts.

Model usage is billed or limited under the user's chosen provider. The publisher does not sell model credits or process payments. Service availability, provider policies and host permissions can affect execution. Support and bug reports are handled through GitHub issues without a response-time commitment.

# Adaptive interview

Continuous grill is part of every evaluate/create/verify/decide cycle. Preserve the user's original scope and answers; inspect facts before asking, select the most consequential unanswered question, record answer source/reason and reopen on new evidence or goal change. `explore --action next|answer|reopen` saves this state. Probes can include environment/resources, primary-source research, prototype trials and comparisons, not only a fixed catalogue. Persist each answer under a stable uncertainty ID. `propose_next_action(goal, observed_state, uncertainties)` ranks unresolved items by stated impact, prefers a supplied probe over a question, and retains confirmed hard constraints. The host supplies task-specific uncertainty judgments; the helper is not an autonomous natural-language classifier.

For batch material processing, establish representative inputs, tolerated errors, disputes requiring human review and the desired output. For exploratory work, clarify evidence and human decision points. For offline work, inspect local capability and the network boundary before considering a model. For an existing pipeline, inspect its interfaces and regression checks first. If three fixed script steps meet the goal, deliver those steps.

Unknown privacy or data destination must be resolved before a cloud call. Unknown optional presentation preferences need not block a local deterministic prototype. Do not repeat an answered question merely because a new context or provider is in use. Explicit user instructions take precedence over inferred task categories.

# Share Agent Worksystem Builder / 双语介绍

## English

Agent Worksystem Builder is an experimental Codex plugin for building complete intelligent systems through ongoing dialogue, adaptive exploration and an evaluate–create–verify–decide loop. It separates the native-conversation Builder, ordinary application architecture and optional intelligence orchestration. A coordinator composes focused Skills for grill, exploration, design, implementation and verification. Targets can run independently; deterministic programs need no extra agents. The 0.2 candidate adds broad contracts and real dual-mode Codex integration. Engineering checks, the 120-attempt qualification matrix, actual human use and official listing are separate evidence gates. No performance-improvement claim is made before matched results.

Source and current status: https://github.com/iyohesohoka646-dotcom/agent-worksystem-builder
